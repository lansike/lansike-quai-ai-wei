# AI 高频词 / 句式替换表

配合 `SKILL.md` 第四节使用。**红线词**改完必须清零；**黄线词**看语境，空了就换，有实际意思就留。

替换原则就一条：**换成具体的话，换不出具体的就删，删了意思不全就用最朴素的说法。** 别拿另一个套话去顶。

例外：引号里的原话、被讨论的词、专业术语、用户明确要求保留的，不动。

---

## 红线词（改完必须 0 处）

### 信号词

| 红线词 | 怎么处理 | 例子 |
|---|---|---|
| 值得注意的是 / 需要指出的是 | 直接删，后面的话提上来 | 值得注意的是，周五停服 → 周五停服 |
| 不难发现 / 显而易见 | 删；真想强调就说“一看就知道”（公众号档、小红书档） | 不难发现，价格涨了 → 价格涨了 |
| 毋庸置疑 / 毫无疑问 / 不可否认 | 删；作者的判断用正常语气说 | 毋庸置疑，这很重要 → 这事很重要 |
| 众所周知 | 删；如果是“大家都知道”的共识，直接说事实 | 众所周知，熬夜伤身 → 熬夜伤身 |

### 铺垫

| 红线词 | 怎么处理 |
|---|---|
| 让我们来看看 / 接下来让我们 | 删，直接给内容 |
| 让我们一起…… | 删；有具体号召（“周五前报名”）就只留号召 |
| 深入探讨 / 深入了解 | “聊聊”“讲讲”“看看”，或者删 |
| 一探究竟 | 删 |

### 时代套话

| 红线词 | 怎么处理 |
|---|---|
| 在当今……时代 / 快节奏的时代 | 整句删；有具体变化就只留变化 |
| 随着科技的不断发展 / 飞速发展 / 日新月异 | 同上 |
| 在……的大背景下 | 同上；背景本身是信息（“在降价潮里”）就直说 |

### 总结收尾

| 红线词 | 怎么处理 |
|---|---|
| 综上所述 / 总而言之 / 总的来说 / 一言以蔽之 | 删；真需要总结就用“所以”“说到底”（公众号档）或直接写结论 |
| 由此可见 / 这意味着 | “所以”“也就是说”，或直接写推论 |
| 让我们拭目以待 / 未来可期 / 共同期待 / 一起见证 | 删 |
| 开启新篇章 / 新篇章 | 删，或写具体变化（“从下月起改成……”） |

### 拔高宣传

| 红线词 | 怎么处理 | 例子 |
|---|---|---|
| 彰显了…… / 标志着…… / 里程碑 / 新时代 | 删尾巴，留事实 | 上线了导出功能，标志着新时代 → 上线了导出功能 |
| 革命性 / 前所未有 / 无与伦比 / 极致 | 删，或换成原文已有的具体特点 | 极致轻薄 → 很薄（原文有 280g 就写 280g） |
| 堪称…… / 天花板 | 删，或改成“我觉得是我用过最……的”（只在原文有这个评价时） |
| 不可或缺 / 至关重要 / 举足轻重 / 重中之重 | “很重要”“最要紧的是”，或写清重要在哪 |
| 全方位 / 多维度 | 删，或列出原文实际有的那几个方面 |
| 深度融合 / 无缝 | “结合”“接上”“直接就能用” |

### 职场黑话

| 红线词 | 换成 | 注意 |
|---|---|---|
| 赋能 | 帮……做到……、让……能…… | 原文没说帮什么，就写“支持” |
| 抓手 | 办法、切入点、具体做的事 | |
| 打通 | 接上、连起来、让 A 和 B 能互相…… | |
| 沉淀 | 整理成（文档/模板）、留下 | 化学沉淀是术语，保留 |
| 颗粒度 | 细到什么程度、多细 | |
| 底层逻辑 / 顶层设计 | 根本原因、整体方案 | |
| 组合拳 | 几个办法一起用 | |
| 对齐 | 确认、统一口径、开会定了 | 排版“左对齐”保留 |
| 闭环 | 跟到底、有结果、做完反馈 | 控制系统“闭环”是术语，保留 |
| 助力 | 帮、让……更…… | |
| 深耕 | 做了 X 年、一直在做 | 年限原文没写就别加 |
| 持续发力 / 稳步推进 / 有序推进 | 写具体进度：“完成了 X，还剩 Y” | |
| 高效协同 | 写谁和谁一起做了什么 | |
| 取得了阶段性成果 | 写成果本身：“完成了 X” | |
| 在……的共同努力下（共同努力下） | 删；要感谢就单独一句“辛苦大家” | |

### 客服腔

| 红线词 | 怎么处理 |
|---|---|
| 好问题 | 删 |
| 希望对您/你有所帮助 | 删 |
| 如有任何问题 / 请随时联系 | 删；真需要对方反馈，写“有问题直接找我”或具体请求 |
| 感谢您的耐心阅读 | 删 |

### 伪口语

| 红线词 | 怎么处理 |
|---|---|
| 那么问题来了 / 你可能会问 / 这就引出了 | 删，直接写问题或答案 |
| 答案可能出乎你的意料 | 删，直接给答案 |

### 不是红线：小红书平台口语

下面这些是平台日常说法，**不是 AI 味**，不进红线表，不算命中，不要为了“去 AI 味”删它们：

绝绝子、家人们、谁懂啊、姐妹们、YYDS、宝藏、闭眼入、姐妹们冲、氛围感拉满、幸福感拉满、狠狠爱住、亲测好用、仪式感满满、不允许还有人不知道。

改小红书稿时盯的是时代套话、假对比、总结收尾、空夸拔高（见上面各节和第三节症状）。平台口语原文有就留；只有用户明确说“少用网络梗 / 去模板味”时，才按他的要求收密度。

### 句式

| 红线句式 | 改法 |
|---|---|
| 不仅仅是 A，更是 B / 不仅是 A，更是 B | 直接说 B；A、B 都是信息时改成“A，也 B” |
| 首先……其次……最后 | “先……再……最后”，或分条不写序数词，或顺着写 |

## 黄线词（看语境）

| 黄线词 | 什么时候改 |
|---|---|
| 不是 A，而是 B | A 是凭空立的靶子时改；A 是真误解时留 |
| 可以说 / 事实上 / 实际上 | 后面没有新事实、没有对比时删 |
| 进行 + 动词 | 改直接动词：“进行测试”→“测试” |
| 做出了……调整 / 优化 | “调了”“改了”，注意保留完成状态 |
| 一方面……另一方面 | 两边都有信息就留，否则顺着写 |
| 赋予 / 打造 / 构建 | 有具体对象时换成具体动词，空的删 |
| 显著 / 大幅 | 原文有数字就用数字，没有就留着（别删程度信息） |
| 某种程度上 / 在一定程度上 | 一句里只留一个限定 |
| 说真的 / 坦率地讲 / 其实吧 | 口语词本身没问题，超过档位上限就是新 AI 味 |
| 冒号“：” | 小红书、公众号档少用；职场档原文有的“风险：”可以留，但不为显得精炼新加 |
| 破折号“——” | 三档都尽量 0 处，改逗号或句号 |
