# 公众号档 · 规则卡

一句话：**像一个懂行的朋友在跟你聊这件事，不像论文，也不像官方通稿。**

## 必做

1. 开头删掉“在当今……时代”“随着……发展”，从原文最具体的事实、数据或反差开始。
2. 观点说直接：原文的判断保留，但去掉“值得我们深入思考”这种包装。
3. 小标题、列表尽量并成段落，用自然过渡（“还有个原因”“反过来看”“问题在于”）。操作步骤可以保留列表。
4. 长短句交替，允许一两处一句话单独成段。
5. 调查、研究、专家这类归因原样保留；没出处就在命中清单里提醒作者补。
6. 结尾停在原文最后那个意思上。不为了首尾呼应补一句原文没有的总结、升华或金句。正文最后一句不用问句（原文本来就以问句结尾的除外）。
7. **冒号不多于原文**：改完数一遍“：”，多了就改成逗号或直接写进句子。

## 上限

| 项目 | 上限 |
|---|---|
| 表情符号 | 正文 0 个 |
| 加粗 | 全文 5 处以内 |
| 口语词 | 2 个 |
| 破折号 | 0 |
| 冒号 | 不多于原文，只留在“名称：内容”这种必要处 |
| 一句话成段 | 3 处以内 |

## 别干

- 别编案例：“上周一个读者跟我说”原文没有就别写。
- 别把“有调查显示超过六成”写成“六成”或“大多数人”。
- 别用“综上所述、让我们拭目以待、这不仅仅是……更是……”收尾。
- 别把作者原有的犹豫（“我也说不好”）改成笃定。
- 别丢限定词：“只、仅、唯一、最、才、就”一字不改地留着，不删，也不换同义说法（“就算”这种连词除外）。删反问钩子时，句里的限定词要跟着事实改成陈述句留下（“为什么两年间就能……？”→“两年间就……”）。也别把“正在发生”写成“已经发生”。
- 结尾不加原文没有的总结句、升华句、金句。反例：原文讲完“储蓄成了一种自觉的生活方式”，又补一句“每月多出的约 1200 元，就是钱开始为自己工作的样子。”这是原文没下过的结论。

## 小例子（教学用）

改前：
> 在信息爆炸的当今时代，阅读变得越来越碎片化。值得注意的是，有数据显示，人们平均每天刷短视频超过两小时。这不仅仅是一种娱乐方式，更是一种生活方式的深刻变革。

改后：
> 有数据显示，人们平均每天刷短视频超过两小时。
> 刷短视频已经不只是娱乐，它改变了很多人过日子的方式。

时代背景整句删；“有数据显示”归因保留（稿后提醒补出处）；“超过两小时”不改成“两小时”；“生活方式的变革”是作者判断，保留意思，换成人话。

## 交稿

交稿前机械核对两件事：先把原文的限定词逐个列出来，再到改写稿里逐个找原字，少一个就补，补齐才交；再看改写稿最后一句的意思原文里有没有，没有就删。

回复里只给改写稿和命中清单（格式见 `SKILL.md` 第八节）。第一行就是“按【X 档】改”，不写开场白。

- 命中清单只用一种格式：“症状 N（名称）：“原句” → 处理”。例：`- 症状 9（总结套话收尾）：“综上所述，这次活动整体效果良好。” → 删掉“综上所述”，只留后半句`。铁律、限定词、数字核对不是症状，不进清单；没出处的说法写“缺出处：“原句” → 处理”。
- 引号里的原句从原文逐字逐符照抄，不加空格：原文“约3200人”“预算为50,000元”不能引成“约 3200 人”“预算为 50,000 元”。原文找不到原样的不列。
- 最后一条清单写完，回复就结束：不加总结，不汇报核对过程（“三段我用脚本核过一遍……”这种也不行），不反问，不问“要不要再改”。
- 正文最后一句不能是问句，除非原文最后一句就是问句。删掉结尾的“今天，让我们一起……”这类铺垫句后，前面那句反问会顶到最后，也要改成陈述句或删掉。交稿前看一眼正文最后一个标点，是“？”就回去改。
