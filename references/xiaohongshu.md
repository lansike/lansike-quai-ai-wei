# 小红书档 · 规则卡

一句话：**像刚用完、忍不住想安利的普通人，不像品牌号小编。**

## 必做

1. 第一句给结论或最狠的点（价格、最大优点、最大槽点），别打招呼。
2. 原文的参数、价格、型号、缺点全部保留，数字不改。
3. 用短句，一行一个意思；可以有“真的”“有点”“还行”这种语气。
4. 话题标签保留原文的，放末尾，最多 5 个；含真正红线词的标签删掉。#宝藏好物 这类平台口语标签不是红线，原文有就留。
5. 结尾停在原文里有的实在东西上（适合谁、多少钱、要注意什么），原文没说的不补。
6. **种草力度不降**：原文在推荐，改完还是推荐。空洞的夸奖换成原文里的具体理由（价格、参数、实测结果、店家说法），不删了事，也不写成劝退；反过来也不加码成“全网最值”“不买后悔”这种夸张推销腔。

## 上限

| 项目 | 上限 |
|---|---|
| 表情符号 | 全文 3 个，不能当项目符号，不能每行一个 |
| 列表 | 一组，只给参数类信息 |
| 口语词（说真的、其实吧之类） | 1–3 个 |
| 破折号 | 0 |
| 感叹号 | 2 个 |
| 推荐力度 | 跟原文持平：不降，也不加码 |

## 别干

- 别编“我用了三个月”“室友都抢着用”，原文没有就没有。
- 别把“店家宣称保温 12 小时”写成“实测保温 12 小时”。
- “绝绝子、家人们、宝藏、闭眼入”是平台口语，不是 AI 味，原文有就留，别当红线清（见 `ai-words.md`）。要改的是“在当今……”“总的来说”“不仅仅是……更是……”这类真正的套话。
- 别丢限定词：“只、仅、唯一、最、才、就”一字不改地留着，不删，也不换同义说法（“就算”这种连词除外）。反例：“售价仅399元”改成“399 块”，“一般只需18分钟”改成“18 分钟就好”，都丢了限定词；“唯一的缺点是有点重”也不能只剩“有点重”。
- 结尾不加原文没有的总结句、升华句、金句，也不加原文没有的购买动员（“想要可以直接下手”“冲就完了”“闭眼入”）。原文的推荐句只能换个说法留着：“是你厨房里的理想选择”可以写成“放厨房很合适”，意思不能往前多走一步。
- 别删缺点。缺点是最像真人的部分。但缺点照实写就行，别借它把全文带成劝退。
- 别把空夸删光后只剩干巴巴的参数，也别换成“可以先看看”“还算能接受”“就是个普通货”这种劝退语气。

## 小例子（教学用）

改前：
> 在当今这个追求精致的时代，选择合适的发饰至关重要。值得注意的是，这款发夹颜值超高！这不仅仅是一个发夹，更是精致女孩的必备单品。19.9 包邮。综上所述，它绝对是你妆造里不可或缺的存在。姐妹们，闭眼入！

改后：
> 姐妹们，19.9 包邮的发夹，颜值超高，闭眼入。
> 就这个价还包邮，妆造用着用着挺合适。

“在当今……至关重要”“值得注意的是”“不仅仅是……更是……”“综上所述”“不可或缺”是 AI 味，清掉；“姐妹们”“闭眼入”是平台口语，不是红线，原文有就留。空的“精致女孩必备单品”换成原文里的价格理由。原文没说夹得牢不牢，就不写。

## 交稿

交稿前机械核对两件事：先把原文的限定词逐个列出来，再到改写稿里逐个找原字，少一个就补，补齐才交；再看改写稿最后一句的意思原文里有没有，没有就删。

回复里只给改写稿和命中清单（格式见 `SKILL.md` 第八节）。第一行就是“按【X 档】改”，不写开场白。

- 命中清单只用一种格式：“症状 N（名称）：“原句” → 处理”。例：`- 症状 9（总结套话收尾）：“综上所述，这次活动整体效果良好。” → 删掉“综上所述”，只留后半句`。铁律、限定词、数字核对不是症状，不进清单；没出处的说法写“缺出处：“原句” → 处理”。
- 引号里的原句从原文逐字逐符照抄，不加空格：原文“约3200人”“预算为50,000元”不能引成“约 3200 人”“预算为 50,000 元”。原文找不到原样的不列。
- 最后一条清单写完，回复就结束：不加总结，不汇报核对过程（“三段我用脚本核过一遍……”这种也不行），不反问，不问“要不要再改”。
